# Public search (web/index.html)

Scope: the public Grant Matcher site, one screen: profile, ranked results by source, before-you-apply checklist. Visitor mode: Operate.

Audience and job: a one-person development team or founder at a small nonprofit, or an advisor searching for several, deciding which grants deserve their limited time; phone as often as laptop, sometimes a screen reader. Success: results fast, reasons trusted, profile easy, a look people remember. Must not feel like a slick startup.

Constraints: Grants.gov notice verbatim; ranking matches Python; one accent, status colors only for meaning; AA in light and dark, visible focus, 44px targets, 320px wide; sentence case, verb buttons, no em dashes.

## Direction contract

THESIS: Grant Matcher is the funding directory on the library reference shelf, rebuilt to read your mission back to you. It refuses the category default of a grey filter sidebar beside interchangeable soft cards.

OWN-WORLD: Navy owns the shell (header band and the selected index tab), with one civic blue accent (palette changed by the user after the first build); page ground is plain white in light and a deep navy-black in dark, never cream. Public Sans for every working word, a sturdy text serif for funder names only. Entries are dense directory listings set on rules, not floating cards: name, catalog number in tabular figures, then run-in facts. Amber only for cautions, red only for errors.

STORY: The visitor sees how many strong matches exist and where, believes each one because the entry states why and what could sink it, then shortlists the few worth pursuing and exports them.

FIRST VIEWPORT: Navy header band with the name, the one-line answer ("30 strong matches...") and the Grants.gov notice. Below, a two-column work area on desktop: the profile form in a quiet left column with Update matches pinned at its foot; the results column with the source index tabs (count on each), then the first entries. On phones the profile collapses to one "Edit your organization" bar above the tabs.

FORM: candidate 3 of 7 (the printed funding directory). seed:3602426d69885eb5. Signature move: every entry carries the same 0 to 100 score rule on one fixed scale with the 35 and 60 marks, beside a right-aligned deadline. Raised by: star atlas (a fixed visual ramp carries rank, so type stays calm), convention catalog (shortlist marks kept on the device, with a count and its own export), Factory catalog sleeve (the catalog number is each entry's key, always in the same place), cassette j-card (deadlines right-aligned in tabular figures for column scanning). Botanical folio and split-flap board declined; kept: one shared scale and fixed columns inside each entry.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
